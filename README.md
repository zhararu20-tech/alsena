# Alsena — лэндинг

Одностраничный сайт центра Alsena: бассейн, тренажёрный зал, фитнес-кружки, сауны, массаж, кафе.

Сайт — один файл `index.html` (стили и скрипт внутри), без сборки. Открывается двойным кликом.

## Как поменять координаты и контакты

Откройте `index.html`, найдите `const CENTER` (начало блока `<script>` внизу файла) и поменяйте значения:

```js
const CENTER = {
  lat: 55.7993985,  // широта
  lng: 37.973108,   // долгота
  zoom: 16,
  address: 'пр. Ленина, 40, Балашиха',
  phone: '+7 (495) 521-40-40',
  whatsapp: '+7 (916) 555-18-42',
};
```

Карта, точка, кнопка «Построить маршрут» (Google Карты), телефоны и кнопки «Записаться» (WhatsApp) обновятся автоматически.

## Как устроена прокрутка

На компьютере каждый поворот колеса мыши (или ↑/↓, PageUp/PageDown) показывает следующий раздел:
карта → бассейн → тренажёрный зал → доп. услуги → контакты.
На телефонах сайт листается обычной прокруткой.
